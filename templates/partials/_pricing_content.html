What counts as a call?

One API call per request to a Synzo tool (summarize, translate, redact, analyze, transcribe). Multi-page documents count as one call up to your plan’s per-call page limit.

Can I use Synzo from Claude Desktop?

Yes — the same plan and quota covers MCP connections from Claude Desktop and direct API key access. Sign up free and connect.

What happens if I hit my quota?

The API returns HTTP 402 Payment Required. Quota resets at the start of each month. Upgrade any time.
