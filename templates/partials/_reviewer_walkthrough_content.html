Synzo MCP — reviewer walkthrough

For Anthropic Connector Directory reviewers. Five tools, one OAuth flow, ~5 minutes end-to-end. Credentials and sample data below; quota provisioned for review.

At a glance

Server URLhttps://www.synzo.ai/mcp
TransportStreamable HTTP (application/json). No SSE branch — synchronous tool shapes only.
Protocol versions2025-06-18, 2025-03-26
AuthOAuth 2.0 via WorkOS AuthKit. DCR per RFC 7591. Augmented /.well-known/oauth-authorization-server injects registration_endpoint — WorkOS supports DCR but doesn't advertise it.
Tools5 — see /docs for the live registry table. Tool catalog is generated at create_app() startup from mcp_tools.TOOLS joined against a sidecar YAML; drift raises at boot.
Resources / PromptsNone implemented.
Sample bundlereviewer-bundle.zip (~3.2 MB — five files, one per tool)

Direct JSON-RPC (curl)

Useful for verifying server health without going through a client. Bearer is the WorkOS JWT; for API-key auth, swap in an sk_synzo_* from /dashboard/keys.

curl -sS -X POST https://www.synzo.ai/mcp \
  -H 'Authorization: Bearer <jwt>' \
  -H 'Content-Type: application/json' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

End-to-end sweep

One prompt per tool, paired with the matching file from reviewer-bundle.zip. Each prompt is written to elicit exactly one tool call; Claude's tool-selection step is the only nondeterminism.

summarize_document · PDF / DOCX / PPTX / XLSX ≤10 MB, ≤20 pages on free tier

File: summarize-sample.pdf · classify + structured summary, no source-text echo

Use Synzo to classify and summarize this document.

→ { classification, summary, filename }

translate_document · DOCX / PPTX / XLSX only (no PDF), ≤10 MB

File: translate-sample.docx · markdown output, no binary round-trip

Translate this document to Spanish using Synzo.

→ { filename, target_language, translated_text }

redact_pii · DOCX / PPTX only, ≤10 MB · Microsoft Presidio

File: redact-sample.docx · in-place redaction, returns base64 + mimetype. Per-paragraph analysis with full default English recognizer set (PERSON, EMAIL_ADDRESS, PHONE_NUMBER, US_SSN, CREDIT_CARD, US_PASSPORT, LOCATION, DATE_TIME, NRP, ORGANIZATION).

Redact the PII in this document using Synzo.

→ { filename, content_base64, mimetype, original_size_bytes, redacted_size_bytes }

All seeded entities — synthetic name, email, phone, SSN (211-61-2524), passport, Visa test card — are replaced with U+2588 block characters. Verifiable end-to-end via scripts/verify_redact_sample.py in the repo.

Cold-start cost: first call on a fresh Waitress process pays ~10–30s for the MTCNN/TensorFlow graph to load. Subsequent calls on the same replica are fast.

Error envelope (for reference)

All tool-layer failures surface as JSON-RPC errors. Auth-layer rejections of tools/call additionally return HTTP 401 with a WWW-Authenticate header so MCP clients can initiate OAuth per spec §2.1 / RFC 9728.

CodeMeaningWhen you'd see it
-32001AuthMissing/invalid bearer; expired token; orphan org; missing JWT claim
-32002QuotaMonthly call cap exhausted
-32003Rate limitPer-org RPM exceeded (cap surfaced in message)
-32004Units exceededPer-call cap exceeded (e.g. >20 pages on free tier)
-32005Tool timeout60s wall-clock ceiling; quota refunded, metered as timeout

Tool-internal failures (handler exception, downstream model error) come back as isError: true in the result envelope — not a JSON-RPC error — so Claude can recover. Quota is still refunded on the exception path.
